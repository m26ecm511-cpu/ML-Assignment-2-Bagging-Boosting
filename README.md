About the Assignment

This repository contains my implementation and experimental results for ML Assignment 2. The work covers decision tree classification, bagging, SAMME boosting, and bias–variance analysis using the Olivetti Faces dataset.

The experiments are implemented in Python using scikit-learn and related libraries. The scripts save the results as JSON files and generate plots for analysis.

Repository Contents

- "run_experiments.py" — runs the experiments.
- "config.json" — contains the experiment configuration.
- "requirements.txt" — lists the required Python packages.
- "make_report.py" — helps generate the report.
- "reproduce.sh" — provides commands for running the project.
- "RUN_IN_COLAB.md" — contains instructions for Google Colab.
- "report_template.md" — report template.
- "outputs/" — contains the final report and experiment results.
- "outputs/figures/" — contains the plots generated by the experiments.

How to Run

Create and activate a Python virtual environment, then install the required packages.

Windows:

python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python run_experiments.py

The first run downloads the Olivetti Faces dataset if it is not already available. The experiment results and plots are saved in the "outputs/" directory.
